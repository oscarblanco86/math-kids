# 🧮 MathKids

Una aplicación web SPA ligera, interactiva y divertida construida con **Vue 3** y **Tailwind CSS**, diseñada para que mi hija practique operaciones de **multiplicación** y **división** con retroalimentación inmediata, estímulo auditivo y respuestas aleatorias.

---

## ✨ Características Principal (MVP)

- ✖️ **Multiplicación:** Generación aleatoria de tablas del 1 al 10.
- ➗ **División Exacta:** Ejercicios sencillos con resultados enteros para practicar cocientes.
- 🔀 **Respuestas Aleatorias:** Cada ejercicio genera 3 opciones alternativas desordenadas al azar para evitar la memorización por posición.
- 📊 **Marcador:** Contador reactivo de aciertos e intentos totales en tiempo real.
- 📱 **Diseño Responsive:** Interfaz optimizada para móviles y pantallas táctiles con botones grandes e intuitivos.

---

## 🛠️ Tech Stack

- **Runtime & Package Manager:** [Bun](https://bun.sh/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Framework:** [Vue 3](https://vuejs.org/) (Composition API con `<script setup>`)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)

## 🚀 Inicio Rápido

### Prerrequisitos

Tener instalado [Bun](https://bun.sh/) en tu sistema.

### Instalación

1. Clona el repositorio:
   ```bash
   git clone [https://github.com/oscarblanco86/math-kids](https://github.com/oscarblanco86/math-kids)
   cd math-kids```

   Instala las dependencias:
2. Bash
    ```bun install```

3. Inicia el servidor de desarrollo:
    ```Bash

    bun run dev```

4. Abre tu navegador en http://localhost:5173.
